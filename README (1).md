# Add the editable ANSYS Workbench project here

The user-supplied material contains screenshots and the assignment brief, **not** the native `.wbpj` / `_files` project. The project was not fabricated or reconstructed.

In ANSYS Workbench, save your final 8 mm / 3 mm solved model, then select **File → Archive...** and export a `.wbpz` Workbench archive. Check that the archive preserves the geometry, assigned custom material, boundary conditions, mesh, static results, and fatigue setup. Put it in this directory if small enough for GitHub.

If the archive is larger than GitHub's regular file limit, consider a tagged GitHub Release asset or Git LFS. Never upload temporary solver files or private license information.
